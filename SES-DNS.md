# Записи DNS для Amazon SES

Добавить в Cloudflare → moneybay.us → DNS → Records.
**Прокси выключен** (серое облако) у всех — это записи почты, не сайта.

## DKIM — три записи CNAME

Подтверждают, что письма отправлены вами.

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `myrr7yfi44lxydu2dfp7y46z3eojcnfu._domainkey` | `myrr7yfi44lxydu2dfp7y46z3eojcnfu.dkim.amazonses.com` |
| CNAME | `nawigckhsawgrmkzoivixto6preztggz._domainkey` | `nawigckhsawgrmkzoivixto6preztggz.dkim.amazonses.com` |
| CNAME | `stdkk7dsblk7tt57zvfnxilhejkcmwru._domainkey` | `stdkk7dsblk7tt57zvfnxilhejkcmwru.dkim.amazonses.com` |

Cloudflare может дописать `.moneybay.us` к имени сам — так и должно быть.

## SPF — одна запись TXT

Говорит почтовым службам, что SES вправе слать письма от вашего домена.

| Тип | Имя | Значение |
|---|---|---|
| TXT | `@` | `v=spf1 include:amazonses.com ~all` |

## DMARC — одна запись TXT

Указывает, что делать с письмами, не прошедшими проверку. `p=none` — только
собирать сведения, ничего не отвергать: так начинают, чтобы не потерять
настоящие письма из-за недосмотра в настройке.

| Тип | Имя | Значение |
|---|---|---|
| TXT | `_dmarc` | `v=DMARC1; p=none; rua=mailto:a.m.marip1987@gmail.com` |

## После добавления

Подтверждение занимает от нескольких минут до суток. Проверить:

```
aws sesv2 get-email-identity --email-identity moneybay.us \
  --query '[VerifiedForSendingStatus,DkimAttributes.Status]' --region us-east-2
```

Нужно `True` и `SUCCESS`.

## Выход из песочницы

Пока SES в песочнице: письма уходят только на подтверждённые адреса, не более
200 в сутки. Для настоящих пользователей нужна заявка.

**Где:** консоль AWS → SES → Account dashboard → Request production access

**Что спросят:**

- **Тип писем:** Transactional
- **Адрес сайта:** https://moneybay.us
- **Зачем шлёте:** подтверждение почты при заведении учётной записи,
  восстановление пароля, уведомления о сообщениях между покупателем и продавцом
- **Как обрабатываете возвраты и жалобы:** через уведомления SES, адреса с
  ошибками исключаются из рассылки
- **Как люди отписываются:** уведомления настраиваются в профиле; письма о
  подтверждении и восстановлении отписки не требуют — они по запросу самого
  человека
- **Откуда адреса:** только те, что люди сами указали при заведении учётной
  записи; покупных списков нет

**Срок:** обычно сутки, иногда двое. Могут задать уточняющие вопросы — отвечать
в том же обращении.
